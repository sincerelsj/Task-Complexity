# README Images

- `experiment-overview-handdrawn.png`: AI-generated conceptual illustration of the task design and search measures. It is an explanatory sketch, not an experimental observation or a results chart.
- `experiment-interface-original.png`: user-provided experiment screenshot, copied byte-for-byte without cropping, resizing, retouching, or re-encoding. Original on-image interface details are retained.

`manifest.json` records the SHA-256 of each reviewed image. The release checker verifies these explicit assets rather than allowing arbitrary binary files. README display sizing does not alter either underlying file.
